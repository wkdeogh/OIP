# OIP

대호와 상희가 함께 사용하는 모바일 우선 생활 관리 웹 앱입니다.

현재 구현 범위:

- 공통 비밀번호와 90일 기기 세션
- 대호/상희 사용자 선택
- 월간 캘린더, 일정·휴무 추가, 매월·매년 반복 일정
- 아이폰 홈 화면 앱용 매일 오전 8시 일정 푸시 알림
- 사용자별 로컬 캐시 우선 표시와 사용 중인 화면 자동 동기화
- TODO와 공동 쇼핑목록
- Google 지도와 여행 목록·링크 및 스크린샷 AI 여행지 분석
- 냉장고 유통기한·수량 관리
- 현재 주차 위치
- 랜덤 여행지·식사 메뉴
- Supabase 서버 전용 데이터 경로와 전체 초기 스키마

로컬 실행과 배포 준비는 [SETUP.md](./SETUP.md)를 확인하세요.

반복 일정은 첫 일정의 날짜를 기준으로 생성하며, 종료일을 지정할 수 있습니다.
31일이나 2월 29일이 없는 달·해에는 그달의 마지막 날에 표시합니다.
여러 날 일정은 원래 기간을 유지하며, 수정·삭제는 반복 일정 전체에 적용합니다.
기존 `calendar_events.recurrence_rule` 필드를 사용하므로 추가 DB 변경은 필요하지 않습니다.
날짜 계산·저장 경로·알림 검증: `node --experimental-strip-types --test tests/calendar-recurrence.test.mjs`
