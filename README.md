# OIP

대호와 상희가 함께 사용하는 모바일 우선 생활 관리 웹 앱입니다.

현재 구현 범위:

- 공통 비밀번호와 90일 기기 세션
- 대호/상희 사용자 선택
- 월간 캘린더, 일정·휴무 추가
- 아이폰 홈 화면 앱용 매일 오전 8시 일정 푸시 알림
- 사용자별 로컬 캐시 우선 표시와 백그라운드 데이터 갱신
- TODO와 공동 쇼핑목록
- Google 지도와 여행 목록·기본 정보
- 냉장고 유통기한·수량 관리
- 현재 주차 위치
- 랜덤 여행지·식사 메뉴
- Supabase 서버 전용 데이터 경로와 전체 초기 스키마

로컬 실행과 배포 준비는 [SETUP.md](./SETUP.md)를 확인하세요.
